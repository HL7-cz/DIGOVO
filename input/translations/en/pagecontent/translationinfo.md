### Languages and translations

**Czech** (`cs`) is the primary and authoritative language of this guide. The English version (`en`) supports international collaboration. The **CZ / EN** navigation switch opens the same page in the other language.

Each page appears only once in the menu. Menu entries and internal links stay in the selected language; only the CZ / EN switch changes language. Czech and English source texts are translations of the same pages, not separate guide entries.

Translations preserve section numbering 1–12 and subsections 2a/2b, model identifiers and canonical URLs. The Czech label **V ŘEŠENÍ – AKTUÁLNĚ NEPLATNÉ** is rendered as **UNDER REVIEW – CURRENTLY INVALID** in English. Both identify the same draft items, 3.7, 7.1 and 7.3, which are currently invalid.

Translations of narrative pages and logical models are included in the IG sources. Inherited FHIR text, dependency profiles and external terminologies may retain their source language where the relevant package or terminology service does not supply a translation. Such text does not constitute a new definition or an officially endorsed terminology translation.

Report translation issues through the [DIGOVO project issue tracker](https://github.com/HL7-cz/DIGOVO/issues). When the Czech source changes, its English translation must be updated accordingly.
